ICT Specialized Paper — Study Guide

Highest-weighted paper (×2). Past papers repeat a predictable core. Master these, then drill the quiz.

1 · What is ICT?

តើ ICT ជាអ្វី?
What is ICT?
A: ICT (បច្ចេកវិទ្យាព័ត៌មាន និងសារគមនាគមន៍) is the technology used to collect, store, process, and share information through computers and communication networks.
  • Benefits: faster communication, easier research, new jobs, better teaching & learning, connecting people worldwide.
  • ICT devices: computer, smartphone, tablet, printer, router, projector, USB, radio, TV.
  • ICT splits into: computer-based technology and digital communication technology.

2 · Hardware vs Software (ផ្នែករឹង / ផ្នែកទន់)

Hardware (ផ្នែករឹង)Software (ផ្នែកទន់)
Physical — you can touch itPrograms / instructions — cannot be touched
CPU, RAM, ROM, Hard Disk, Monitor, Mouse, Keyboard, Motherboard, VGASystem SW (Windows, Linux, Mac OS) & Application SW (MS Office, browsers)

Software has two types: System software runs the machine (the OS) · Application software does tasks for the user.

3 · How a Computer Works — 4 Units

  • Input Unit (បញ្ចូល) — keyboard, mouse → send data to CPU
  • CPU (ខួរក្បាល) — processes data. Has ALU (Arithmetic & Logic Unit) + CU (Control Unit)
  • Memory Unit (អង្គចងចាំ) — RAM holds data while the CPU works
  • Output Unit (បញ្ចេញ) — monitor, printer → show results

4 · Key Hardware Terms

RAM និង ROM ខុសគ្នាយ៉ាងណា?
RAM vs ROM?
RAM = temporary memory, lost when power off (volatile). ROM = permanent, read-only, kept without power.
LAN និង WAN ខុសគ្នាយ៉ាងណា?
LAN vs WAN?
LAN = small area (one building), fast. WAN = large area (cities/countries); the Internet is the largest WAN.
គ្រឿងផ្គុំកុំព្យូទ័រមានអ្វីខ្លះ?
Parts to build a computer?
Motherboard, CPU, RAM, Hard Disk, VGA, Monitor, Mouse, Keyboard, Power Supply, Case.

5 · Internet & Web (អ៊ីនធឺណិត)

អ៊ីនធឺណិត ជាអ្វី?
What is the Internet?
The world’s largest network for communication and sharing information, connecting computers worldwide.
  • Web Browser: program to view web content — Chrome, Firefox, Edge, Opera (Khmer: Mekhala).
  • WWW = World Wide Web · Website = set of web pages · Homepage = first page.
  • Email = Electronic Mail · Google’s free email = Gmail.
  • Download = get data from internet · Upload = send data to internet.
  • DHCP = auto-assigns IP addresses · Static = IP set manually, fixed.

6 · Khmer Software & Open Source

  • Khmer OS fonts: Khmer OS, Battambang, Bokor, Content, Moul, Siemreap, System.
  • Open Source (កូដចំហ): code open, usually free — Linux, OpenOffice, Mekhala, Moyura.
  • Closed/Proprietary: owned, usually paid — Microsoft (Windows, Office), Adobe (Photoshop).
  • Operating systems: Windows, Mac OS X, Linux, Sun Solaris.

7 · Programming, Algorithms & Numbers

  • Algorithm (ក្បួនដោះស្រាយ): step-by-step instructions to solve a problem.
  • Flowchart (ប្លង់ប្រតិបត្តិ): diagram of an algorithm (start/end, process, decision, I/O).
  • Be ready to write both an algorithm and a flowchart, e.g. solving ax + b = 0 (2022 paper).
  • Binary (គោល ២): only 0 & 1. Practice subtraction e.g. (1000101)₂ − (101100)₂.
  • Know: C++ Statement, ASP vs ASP.NET, Samba (file/print sharing), Testing.

General Knowledge & Pedagogy

100 points, 1 hour. Teaching methods, ethics, Cambodian society/economy, and education policy.

1 · Teaching Methods (វិធីសាស្ត្របង្រៀន)

  • Student-centered teaching: teacher facilitates; students participate, discuss, practice.
  • A lesson plan has: objectives, materials, methods, activities, assessment.
  • Assessment: formative (during) & summative (end of unit).
  • Active learning: group work, Q&A, demonstration, project-based, ICT in class.

2 · Teacher Ethics (ក្រមសីលធម៌គ្រូ)

  • Respect students, colleagues, community; treat all students equally.
  • Honesty, responsibility, punctuality, confidentiality of student info.
  • Follow MOEYS professional standards & code of conduct.

3 · Society, Economy & Policy

  • National education priorities: curriculum reform, ICT/digital in education, teacher-quality reform.
  • Key economic sectors: agriculture, garment/textile, tourism, construction.
  • Role of ICT in national development & modernizing education.
  • Policy themes: good governance, transparency, justice, effective civil service.

4 · Model Essay Prompts

ហេតុអ្វីអ្នកចង់ក្លាយជាគ្រូ ICT?
Passion for technology + desire to prepare students for a digital future; real industry experience to share.
ICT ជួយកែលម្អការអប់រំដូចម្តេច?
Access to information, interactive lessons, distance learning, digital skills for jobs.

Practice Tasks

  • Reading: read a short tech paragraph, answer comprehension questions.
  • Grammar: present/past simple, articles (a/an/the), prepositions.
  • Writing: 5–8 sentences — “Why do you want to be a teacher?”
  • Vocabulary: define each ICT word above and use it in a sentence.
Sample prompt: “Explain in a short paragraph how computers help students learn.” Keep sentences short and correct rather than long and risky.

Study Plan & Exam-Day Tips

7-Day Focus

  • Days 1–3: ICT core — hardware/software, 4 units, RAM/ROM, LAN/WAN.
  • Days 4–5: Internet & web, Khmer software, open vs closed, shortcuts.
  • Day 6: Algorithms, flowcharts, binary, basic C++.
  • Day 7: Pedagogy — methods, ethics, policy.
  • Daily: 20 min English vocab + one short writing task.

Exam-Day Tips

  • Read each question fully; note point value; manage time.
  • For essays: define first, then give examples — examiners reward examples.
  • For algorithm questions: always show both steps and diagram.
  • Write neatly. For English, short correct sentences beat long risky ones.
  • Bring ID, arrive early, confirm the venue the day before.
